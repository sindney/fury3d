## 11. Shadow-receiving for particles + transparents (2026-08-03, user directive — supersedes 9.3)

**Design decision (material-level vs particle-level):** the flag lives on the particle system's `RendererModule` (`receiveShadows`, default true, ALPHA blend only — ADDITIVE is light-emitting by convention and never shadowed). Rationale: the emissive-vs-lit distinction is per-SYSTEM (fire vs smoke), co-located with `blendMode` where the artist already makes that call. Mesh transparents take NO flag: the per-light additive loop applies each light's shadow factor automatically — that matches the deferred path's opaque behavior (lights cast or they don't) and keeps the material model simple. Fire stays emissive; smoke dims in shadow with an ambient floor (`u_shadow_floor` 0.25).

**Plumbing facts established before writing code:**
- Point light shadows: 512² DEPTH24 cube map, `texture(shadow_buffer, dir).x * light_radius` vs `length(dir)`, slope/distance-scaled bias (PointLight.glsl:166-177). Particles have true world pos → no shadow_matrix needed (just light pos + radius). The test scene (`outdoor_water`, user-edited 2026-08-03) has the Fire POINT light with `cast_shadows: true` moved so the pile occludes it — that's the v1 target.
- Directional: single 1024² DEPTH24 + deferred-convention view-space matrix; cache the matrix per light for the transparent pass. CSM (the scene's `cascaded_shadow_map: true`) is OUT of v1 scope — a cascaded directional binds u_shadow_type=0 (no shadow) rather than sample the wrong map.
- `Texture::ReleaseTemporary` returns shadow maps to a spec-keyed pool mid-frame — a second same-spec caster's shadow draw would pop and overwrite the first light's map before pass_transparent reads it. Fix: defer ALL shadow-temp releases to end of `Execute` (`m_FrameShadowTemps`).
- Pass order: pass_light (1) → pass_transparent (3), so shadow maps exist by transparent time.

- [x] 11.1 `RendererModule.receiveShadows` (default true) + Load/Save + editor checkbox in the Renderer section.
- [x] 11.2 Defer shadow-temp releases to end of Execute; cache dir shadow matrix per light (`m_LastShadowMatrices`).
- [x] 11.3 ParticleShader: `v_world_pos` varying + `u_shadow_type` (0/1=point/2=dir) + cube/2D sampling with bias + `u_shadow_floor`; bind in the particle draw block from the first shadow-casting light with a cached map; `u_receive_shadows` = ALPHA && module flag. Two-part fix: (a) both `shadow_map`/`shadow_buffer` are ALWAYS bound (real map when active, new 1×1 `GetDummyCubeTexture()`/`GetDummyTexture2D()` fallbacks otherwise) in `ParticleRenderer::FinishDraw` AND `PrelightPipeline::DrawUnit` (Forward path — latent engine-wide transparent breakage otherwise); (b) the diffuse bind went from the unit-only overload (which left unit 0 to be OVERWRITTEN by the first named shadow bind → black texture) to the named `BindTexture("diffuse", tex)` (sets the sampler + advances the unit). Verified: fire preview bright, smoke preview structured, scene capture shows flame + smoke at the pile with tree shadows intact. Interactive A/B still available via the receiveShadows checkbox.
