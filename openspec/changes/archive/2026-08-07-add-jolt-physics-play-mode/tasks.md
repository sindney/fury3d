## Known traps (do not re-derive)

- **Scaled ancestors**: outdoor `RootNode` is ×100 with non-uniform node scales; static bodies bake the world matrix into the shape, dynamic/character write-back goes through parent-world inverse + `MathUtil::Decompose` (never piecewise `GetWorld*` reads).
- **Skinned ×100 scale stays on the fox's SceneNode** — strip it and the bindpose breaks.
- **CPU index data can be freed** by `SubMesh::DeleteRawData` on rendered meshes — collision meshes referenced by BodySetup must retain CPU data (task 2.5).
- **Jolt mesh shapes are static-only** — dynamic + mesh → convex hull fallback (log once).
- **glTF importer does not attach Animator** — the setup script adds it explicitly; clips arrive named `Survey`/`Walk`/`Run`.
- **Editor camera leaks into scene saves** (4 stray nodes in outdoor_water.bin today) — the editorOnly flag + Editor.lua dedupe fixes the root cause; play temp saves inherit the fix.
- **Signal::Connect takes member-fn pointers, not lambdas** — controller/world tick hooks are member functions on `shared_ptr` receivers.
- **One component per type per node** (`m_Components` keyed by `type_index`) — BodySetup and each controller are single-instance per node by construction.
