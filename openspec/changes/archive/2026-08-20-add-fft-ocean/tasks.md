# Tasks

Conventions: ASCII-only source (checked by `tests/check_engine_ascii.py`);
LF line endings; every sampler bound every draw (GL sampler-target trap);
headless verification via `./fury exec <scene> <script.lua>` (no GL), visual
verification via windowed `--screenshot`; engine units are cm (gravity
-981); scene builders are re-runnable and never write their source scene.
Compute shaders are GL 4.3+ and never exist on macOS (GL 4.1 ceiling):
every compute consumer gates on `HasEffectiveCompute()`, and every test
must pass with compute unavailable.
