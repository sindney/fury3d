# add-particle-system-fire-smoke-editor

Implement a Unity-style Particle System (CPU-driven billboard particles with shape/color/size/velocity/lifetime over lifetime modules). Drop smoke + fire emitters into outdoor_water.bin above the lit wood pile. Generate fire/smoke textures with Python noise. Add a per-asset Particle editor in furye that reuses the mesh editor's 3D preview (render a billboard quad with the particle shader into the same FBO/OrbitState pipeline).
